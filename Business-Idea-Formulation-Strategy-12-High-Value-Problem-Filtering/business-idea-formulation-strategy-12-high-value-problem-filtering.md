# Strategy 12: High-Value Problem Filtering

## 🎯 Core Strategy
Identify and filter problems based on specific high-value criteria: problems that are growing, urgent, expensive to solve, mandatory, and frequent.

## Process

### Problem Criteria
Focus on problems that meet ALL or MOST of these criteria:

1. **Growing** - The problem is increasing in frequency or impact
2. **Urgent** - The problem requires immediate attention
3. **Expensive to Solve** - Solving the problem currently costs significant money
4. **Mandatory** - The problem must be addressed (not optional)
5. **Frequent** - The problem occurs regularly or repeatedly

**Find problems that are:**

## Key Advantage
This method ensures you're focusing on high-value problems that have strong market potential, urgency, and willingness to pay, maximizing your chances of building a successful business.

## Problem Evaluation Checklist

When evaluating a problem, check if it meets these criteria:

- [ ] **Growing**: Is this problem becoming more common or severe?
- [ ] **Urgent**: Do people need to solve this problem immediately?
- [ ] **Expensive to Solve**: Does solving this problem currently cost significant money?
- [ ] **Mandatory**: Is solving this problem required, not optional?
- [ ] **Frequent**: Does this problem occur regularly?

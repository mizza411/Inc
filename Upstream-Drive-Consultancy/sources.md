## D. How to re-check a link

1. Open the URL (or the DC `sources.md` row it mirrors).  
2. If it fails, search the title on the publisher’s site (NDPC, NCC, PCI SSC, World Bank, Uptime, ISO).  
3. Update the row here **and** the DC sources row if both cite it.  
4. Do not delete a claim from a topic file until you know it was wrong.

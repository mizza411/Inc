# Lean roles — essential skilled personnel

**Company:** Upstream Drive Consultancy  
**Task:** UDC-1 · Phase 2c  
**Date:** 2026-09-24  
**Who it is for:** You, staffing a **lean** consultancy (outsourced / fractional OK).  
**Pair with:** `offer_lines.md` · `company_requirements.md` · `risk_management_requirements.md`  
**Not this file:** Job ads, salary bands, CAC filings, or a large org chart.

**Principle:** One person cannot honestly cover Lines **A–D** at once. Keep the firm as **lean** as possible: few seats on payroll; buy skill when a line opens; never invent titles you do not need.

---

## 1. How to read this roster

| Label | Meaning |
|-------|---------|
| **Core** | Must be identifiable before that line’s first invoice (you, employee, or named fractional with a contract) |
| **Fractional / outsource** | Hired for the engagement or on a standing thin retainer — not full-time until volume forces it |
| **Later** | Only when a lock flips (e.g. DPCO apply, all-week watch, QSA path) |
| **Not us** | Client, cert body, insurer, or a different licensed trade — Upstream does not fill this seat |

Overlap is allowed (e.g. same person does A + D) **only** when they will not call a workshop a certificate, will not test without a letter, and will not print “24/7” alone.

## 2. Essential seats (lean map)

| Seat | Skills (plain) | Serves | How to fill (lean default) | Do not |
|------|----------------|--------|----------------------------|--------|
| **R1 — Engagement lead / owner of promises** | Scope, contract, refusals, who stamps / who owns residual risk | A–D | **Core** (founder or one named lead) | Let juniors invent claims in section 2 of `company_requirements.md` |
| **R2 — Readiness & training facilitator** | Gap lists, policies, evidence coaching, awareness / implementer workshops for NDPA / ISO / PCI **readiness** | **A** (and supports **D** treatments) | **Core** when A is open; else fractional | Say “we certified you”; act as QSA / DPCO without licence |
| **R3 — Authorised tester** | Scoped testing under a **written letter**; business-word reports; **no method in marketing** | **B** | **Fractional / outsource** until B volume is steady; proof of skill buyer already names (**check this** tender) | Access without letter; “licence to hack”; first client = bank payment core on slides alone |
| **R4 — Watch triage** | Acknowledge named alerts in sold hours; call client’s named person; log / delete hygiene | **C** | **Core or fractional** for first **weekday** client + **named leave backup** (can be fractional) | Print 24/7 with one phone; fix servers under watch fee; physical patrol |
| **R5 — Risk facilitator** | Context → list → options → owner sign-off; link treatments to A/B/C | **D** | Often **same as R2** (fractional OK); separate seat only if conflict or volume | Own residual risk; sell D as a cert or a test |
| **R6 — Counsel (external)** | Letter template (B); PI wording; NDPA processor terms; CNII caution | A–D (as needed) | **Outsource** — standing counsel, not payroll | Skip counsel on B letter “to save money” |
| **R7 — Insurer / broker (external)** | PI that names the line being sold | A–D | **Outsource** | Invoice without PI path decided |

**Not Upstream seats:** accredited ISO auditor, NDPC as stamp, listed QSA, client’s board, night guard, client’s sysadmin for fixes (unless a separate hands contract — out of v1 lean pack).

## 3. Minimum headcount by stage (lean)

| Stage | What is open | People you must be able to name |
|-------|--------------|----------------------------------|
| **Open A only** | First readiness / training project | **R1** + **R2** (may be one person) + **R6/R7** on call |
| **Add D** | Risk picture for a decision-owner | **R5** (often = R2) + R1 |
| **Add B** | First authorised test | **R3** under contract + R1 + counsel-seen letter (**R6**) |
| **Add C weekday** | First monthly watch | **R4** + **leave backup** + R1; list already exists |
| **Lengthen C day** | Longer than one window | Second person who knows that list |
| **C all-week** | 24×7-style promise | Rota + handover + desk power / second path — **Later**; not opening lean |
| **DPCO apply** | Upstream as DPCO | ≥2 qualified staff on the NDPC file — **Later** |
| **QSA path** | Listed assessor | **Later** / usually **not** lean v1 |

**Hard lean rule:** Do not hire R3 full-time before a real B pipeline. Do not hire a night rota before C all-week is sold and powered.

## 4. One person — what they may combine

| Combination | OK when | Not OK when |
|-------------|---------|-------------|
| R1 + R2 | First A clients; refusals stay honest | They start selling B without R3/letter |
| R2 + R5 | Same facilitator; separate A vs D contracts | Risk report pretends to be a certificate |
| R1 + R4 | Founder does weekday triage + backup named | Backup is fictional |
| R2 + R3 | Same human has both skill sets **and** letter discipline | “Readiness” used as cover for unscoped access |
| R3 + R4 | Rare; only with clear hours so test windows ≠ watch hours | Test work billed as watch |

Default lean story: **founder = R1 (+ R2/R5)**; **R3 on call**; **R4 when C opens**; **R6/R7 outside**.

---

## 5. Outsource / fractional checklist

Before naming someone “our tester” or “our watch”:

- [ ] Written subcontract or engagement letter (scope, confidentiality, no client stamp claims)  
- [ ] PI story clear (theirs, yours, or both — **check this**)  
- [ ] For R3: sample redacted report + letter process they accept  
- [ ] For R4: acknowledge SLA they can meet in the sold hours  
- [ ] You still own the client relationship and the refusals list  

Buying software (ticket tool, evidence share) is **not** hiring a seat.

## 6. Roles you refuse to invent early

| Fake / early seat | Why lean skips it |
|-------------------|-------------------|
| Full SOC / night NOC | Line C all-week only |
| In-house lawyer | Counsel retainers scale better |
| Marketing department | One public page is enough at start |
| Physical security manager | Not a sold product |
| Certification body staff | Stamp is never yours in v1 |
| “Growth hacker” / heavy sales floor | Delivery skill first |

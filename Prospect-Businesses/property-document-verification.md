## Problem

People who buy or sell land need the papers checked against the official record before money changes hands. Bad papers and a second sale of the same plot are a known risk. This file records that check as a business idea. It does not start a service, and it does not start an app.

## Why this is a prospect

- Frequent, because land deals keep happening and each deal needs a document check
- Expensive when the papers are wrong, because the buyer can lose the plot
- Fits Nigeria now because land title still moves through a manual government search, and many firms still track deals in chat and spreadsheets
- The sell-or-not question is still open

## MVP sketch

- **Scope:** A human check of real-estate documents for a buyer or a seller. Review the papers they already hold, record what was reviewed, and hand back a plain written result. No new app.
- **Est. cost (USD):** `(blank)`
- **Platforms:** by hand, using the client's own papers and a written result

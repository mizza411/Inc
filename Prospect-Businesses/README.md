# Prospect businesses

Curated shortlist of businesses **not started yet** but with **strong prospects**.

This folder is the middle step in the Inc flow:

**Problem identification → Formulated ideas → Prospect businesses → Started businesses**

| Folder | Meaning |
|--------|---------|
| `agent-business-idea-runs/outputs/` | Raw formulation runs (history) |
| `business_research/` | Deep research / long plans (stay put) |
| **`Prospect-Businesses/`** | Shortlist you are seriously considering (~**5–10** active) |
| `Started-Businesses/` | Running or committed businesses (e.g. software) |

## Rules

1. **Shortlist only** — do not dump every idea from `business_ideas_YYYYMMDD.md` here.
2. **One markdown file per prospect** — copy `TEMPLATE.md`, rename to a clear slug (e.g. `examfee-planner.md`).
3. **Link back** to the source formulation run (e.g. `../agent-business-idea-runs/outputs/business_ideas_20260712.md`).
4. **No bulk import** from strategy folders or research archives.
5. **Graduation is user-only** — see below.

## Graduation (user approval required)

Moving or copying a prospect into `Started-Businesses/` requires **your explicit approval** every time.

Agents must:

- Propose graduation in chat/menu only
- **Never** auto-move, auto-rename as “started,” or treat Hub/bookmark filing as graduation

Checklist when you approve graduating prospect **X**:

1. You say clearly: graduate **X** (or reply with the menu number that means graduate).
2. Create or update the matching file under `Started-Businesses/`.
3. Mark the prospect file `status: graduated` (or archive/remove from the active shortlist).
4. Do not delete formulation history under `agent-business-idea-runs/outputs/`.

## Template

Use [`TEMPLATE.md`](TEMPLATE.md) for each new prospect.

Each prospect can have a sibling `{slug}-funding.md` copied from [`FUNDING_TEMPLATE.md`](FUNDING_TEMPLATE.md), which is a funding note and not a second prospect, and moving a prospect to Started businesses still needs an explicit yes.

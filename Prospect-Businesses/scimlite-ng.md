## Problem

## Why this is a prospect

- **GUEMF:** Growing / Expensive / Mandatory / Frequent-ish (composite **19**; urgency moderate)
- Unlocks enterprise deals; sticky once integrated
- Strong founder fit: API/integration work matches software agency profile  
- Mainly **Strategy 7** (trending adapt) with light LegalTech×Identity niche label — not a Crunchbase niche-combo idea

## MVP sketch

- **Scope:** Lightweight SCIM 2.0 bridge for SMB SaaS: IdP groups → app roles → audit log → revoke on offboard; NDPA retention notes  
- **Est. cost (USD):** $12k–$26k  
- **Platforms:** web / API  
- **Target:** Nigerian SaaS founders selling into banks, insurers, telcos; IT consultancies packaging SSO  
- **Regulatory notes:** NDPA; CBN/cybersecurity buyer questionnaires; not a licensed IdP

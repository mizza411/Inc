# YouTube Business Automation

Automated faceless video pipeline: English–Yoruba language blending, trending topics, scripts, research, subtitles, and performance tracking.

## Quick start

```powershell
cd Strategy-2-Problem-Solving\Content-Automation\youtube
pip install -r requirements-phase3-minimal.txt
python main.py status
python main.py create "Afrobeats" music
```

```powershell
python main.py launch --dry-run   # Plan 12 launch videos

python main.py monitor            # Health alerts
python main.py test               # Run test suite
python main.py monetization check    # YPP readiness
```
